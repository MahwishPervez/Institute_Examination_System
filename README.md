# 🎓 Institute Examination System (IES)

A comprehensive **web-based Institute Examination System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The system digitizes examination management by providing dedicated portals for **Students**, **Teachers**, and **Administrators**, making academic examination processes secure, efficient, and paperless.

---

## 📌 Features

### 👨‍🎓 Student Portal

* Secure Registration & Login
* Online Examination Form Submission
* View Profile
* Download Admit Card
* Download Marksheet
* Download Migration Certificate
* Track Examination Fee Status
* View Attendance Status
* View Backlog Information

### 👨‍🏫 Teacher Portal

* Secure Login
* Dashboard
* Enter Internal & End Semester Marks
* Manage Student Examination Records

### 👨‍💼 Administrator Portal

* Role-Based Dashboard
* Manage Students
* Manage Teachers
* Manage Examination Records
* View Submitted Examination Forms
* Manage Academic Documents
* User Management
